# Changelog

История изменений аддона. Формат основан на Keep a Changelog.

## [Unreleased]

Записи для следующего релиза добавляются в этот раздел.

### Fixed

- Рецепты с продукцией «Становится персональным при получении» (BoP, bind 1)
  и «Привязывается к отряду» (Warband, bind 8/9) не учитываются: исключены
  из скана, не пишутся в SavedVariables, чистятся из старых сейвов при
  загрузке и не попадают в очередь цен аукциона.
- Исправлено чтение bindType из `C_Item.GetItemInfo`: брался 13-й возврат
  (subclassID, у декора часто 0) вместо 14-го (bindType), из-за чего
  BoP/Warband-предметы опознавались как продаваемые и всё равно попадали
  в таблицу. Теперь bind читается через `select(14, ...)`.
- Поднят `PRICE_TTL` 900 → 3600 (1 ч; окно чтения из SavedVariables x2 = 2 ч):
  цены аукциона больше не слетают между сессиями с перерывом до 2 часов.
- BindType 3 (OnUse, «Использование: ...») считается продаваемым: белый список
  расширен 0/2 → 0/2/3. Предметы BoU продаются на АХ до использования
  (кодексы, инструменты, маунты), раньше такие рецепты молча отбрасывались
  в счётчик «непродаваемых пропущено».

### Added

- `/dlp debug skipped` — поимённый список рецептов, пропущенных последним
  сканом как непродаваемые (`имя, spellID, outputItemID, bind`), вместо
  голого счётчика. `DebugSpell` отдаёт `bindType`/`unsellable`, мета скана —
  `skippedSample`/`bindHistogram`, доступно `Core:LastSkipped()`.

## [2.0.0] - 2026-09-10

### Added

- Виртуализация строк таблицы и перерасчёт видимого диапазона.
- Изменение размера главного окна.
- Диагностика подсистем, self-test и bug bundle.

### Changed

- Код аддона разделён на сервисы, UI-модули, данные и утилиты.
- Очередь аукционных запросов получила пакетную обработку и прогресс.

### Fixed

- Удалены вызовы устаревших методов изменения размера Frame API.
