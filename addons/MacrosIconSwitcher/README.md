# MacrosIconSwitcher

Небольшой аддон для World of Warcraft (Retail 12.1.0 / Midnight): назначает макросам
свои иконки и автоматически применяет их при входе в игру.

## Установка

Скопировать папку `MacrosIconSwitcher` в `World of Warcraft\_retail_\Interface\AddOns\`.

## Использование

1. В игре ввести `/mis` — откроется таблица со всеми макросами (общие 1–120 и
   персонажа 121–150).
2. Поставить галочку в колонке **Вкл** у нужного макроса — справа появятся поле для
   **ID иконки** (FileDataID, например `135432`), кнопка «…» и колонка **Новая**
   с превью.
3. Ввести ID и нажать Enter — или открыть пикер кнопкой «…» и выбрать иконку из
   списка. Иконка применится сразу и сохранится.
4. При следующем входе в игру иконки будут выставлены автоматически.

## Команды

| Команда | Действие |
|---|---|
| `/mis` (или `/macroicons`) | открыть/закрыть окно |
| `/mis apply` | применить все сохранённые иконки сейчас |
| `/mis on` / `/mis off` | включить/выключить авто-смену при входе |
| `/mis reset` | очистить сохранённые иконки |
| `/mis help` | помощь |

## Как это работает

- Список макросов читается через `GetNumMacros` / `GetMacroInfo`.
- Иконка задаётся `FileDataID` и применяется через `EditMacro(index, nil, iconID, nil)`
  (имя и тело макроса не меняются).
- Пикер берёт иконки из `GetMacroIcons` / `GetMacroItemIcons`.
- Конфигурация хранится в `MacrosIconSwitcherDB` (account-wide): общие макросы —
  по **имени**, персонажные — по ключу **«персонаж|имя»** — так назначение переживает
  смену слотов, а одноимённые макросы не конфликтуют.
- Кнопка у миникарты: ЛКМ — окно, ПКМ — показать/скрыть кнопку, перетаскивание
  меняет позицию (сохраняется). Управление — чекбоксом «Миникарта» в окне.
- Применение идемпотентно: если иконка уже совпадает, вызов пропускается.
- В бою макросы защищены (`InCombatLockdown`) — применение откладывается до
  `PLAYER_REGEN_ENABLED`.

## Структура

```
MacrosIconSwitcher.toc   порядок загрузки
Locales.lua              тексты (enUS, ruRU, deDE, frFR, esES, esMX, ptBR, itIT, zhCN, zhTW, koKR)
Init.lua                 неймспейс, VERSION, SavedVariables (schema 2)
Config.lua               размеры/цвета UI, пикер, миникарта
Core.lua                 чтение макросов, применение иконок, миграция схемы
UI.lua                   окно-таблица (чекбокс + поле ID + пикер + превью)
Minimap.lua              кнопка у миникарты + Addon Compartment
Commands.lua             слэш-команды и события
```
