# Changelog

Все заметные изменения аддона MacrosIconSwitcher.
Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), версии — SemVer.

## [1.0.0] - 2026-09-15

### Added

- Первая версия аддона.
- Таблица всех макросов (общие и персонажа) со чекбоксом и полем ID иконки.
- Применение иконки через `EditMacro` по `FileDataID` сразу при вводе.
- Автоматическая смена иконок при входе в игру (с отложенным повтором в бою).
- Команды `/mis` и `/macroicons`: открыть окно, `apply`, `on|off`, `reset`, `help`.
- Локализация enUS/ruRU.

### Fixed

- `/mis` падал в `UI.Build`: `headerLabel` вызывал `SetWidth(nil)` для колонки без ширины. Теперь `SetWidth` только при заданной ширине.
- После сбоя `UI.Build` окно оставалось полупостроенным (`UI._frame` выставлен, `_scrollChild` нет), и следующий `/mis` падал в `UI.Refresh`. Теперь окно публикуется только после полной сборки (`UI._built`), а `Refresh` защищён проверкой `_scrollChild`.
