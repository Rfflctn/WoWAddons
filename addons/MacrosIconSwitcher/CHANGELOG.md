# Changelog

Все заметные изменения аддона MacrosIconSwitcher.
Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), версии — SemVer.

## [1.1.0] - 2026-09-15

### Added

- Пикер иконок: кнопка «…» у поля ID открывает окно-грид со всеми доступными для макросов
  иконками (`GetMacroIcons` / `GetMacroItemIcons`) — ручной ввод FileDataID больше не обязателен,
  но поле остаётся рабочим.
- Колонка «Новая»: превью иконки, которая будет применена (видно до применения).
- Разделение сохранённых иконок на общие и персонажные макросы: общие хранятся по имени,
  персонажные — по ключу «персонаж|имя» (SavedVariables — account-wide). Одноимённые
  общий и персонажный макросы, а также одноимённые персонажные макросы разных персонажей
  больше не конфликтуют.
- Кнопка у миникарты: клик — окно аддона, ПКМ — показ/скрытие, перетаскивается по кругу
  (позиция сохраняется). Плюс регистрация в панели Addon Compartment (клик открывает окно).
- Чекбокс «Миникарта» в окне аддона: показать/скрыть кнопку у миникарты.
- Локализации: deDE, frFR, esES, esMX, ptBR, itIT, zhCN, zhTW, koKR (раньше были enUS/ruRU).

### Changed

- `DB_SCHEMA` 1 → 2: старый плоский список иконок (ключ — только имя макроса) переносится
  без потери: записи хранятся в `db.legacyIcons` и при первом входе в игру связываются
  с живым списком макросов по имени (общий макрос → общий бакет, персонажный → бакет
  персонажа; ненайденные имена остаются в общем бакете). Старые SavedVariables
  подхватываются автоматически, миграция выполняется один раз (`db.schemaVersion = 2`).

### Fixed

- Кнопка у миникарты не создавалась: локальная таблица модуля `Minimap` затеняла
  глобальный фрейм `Minimap`, позиционирование кидало ошибку, которую гасил `pcall`.
  Локал переименован (в файле используется `_G.Minimap`).
- Открытие пикера иконок вешало клиент намертво: грид создавал кнопку на каждую
  иконку (~10 000 фреймов/текстур). Теперь грид виртуализирован: фиксированный пул
  кнопок отрисовывает только видимые строки, содержимое обновляется на скролле.
- `SetTexture` с невалидным FileDataID больше не может оборвать рендер/обновление
  таблицы: превью в строке и иконки в пикере применяются через защищённый вызов,
  битые ячейки просто скрываются.
- Позиция кнопки у миникарты больше не привязана к радиусу 80: радиус вычисляется
  динамически (`ширина миникарты / 2 + отступ`), учитывая увеличенную карту и её
  масштаб. Отступ настраивается в `Config.MINIMAP.PADDING`.
- Окно пикера иконок открывается слева от главного окна (не перекрывая таблицу
  и кнопки «Применить»/«Обновить»); если у края экрана — прижимается к границе.
  Окно можно перетаскивать мышью.

## [1.0.0] - 2026-09-15

### Added

- Первая версия аддона.
- Таблица всех макросов (общие и персонажа) со чекбоксом и полем ID иконки.
- Применение иконки через `EditMacro` по `FileDataID` сразу при вводе.
- Автоматическая смена иконок при входе в игру (с отложенным повтором в бою).
- Команды `/mis` и `/macroicons`: открыть окно, `apply`, `on|off`, `reset`, `help`.
- Локализация enUS/ruRU.

### Fixed

- `/mis` падал в `UI.Build`: `headerLabel` вызывал `SetWidth(nil)` для колонки без ширины. Теперь `SetWidth` только при заданной ширине.
- После сбоя `UI.Build` окно оставалось полупостроенным (`UI._frame` выставлен, `_scrollChild` нет), и следующий `/mis` падал в `UI.Refresh`. Теперь окно публикуется только после полной сборки (`UI._built`), а `Refresh` защищён проверкой `_scrollChild`.
